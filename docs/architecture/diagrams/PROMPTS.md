# GPT-generated diagram prompts

Built-in GPT image generation was used for the four transparent PNG assets. No Python, SVG or XML was used to draw or edit diagrams. Labels are embedded in the generated images; titles and explanations are in the PDF and Markdown. Images are explanatory proposed views; the text contracts are authoritative.

## architect-2

Use case: infographic-diagram. Generate a sophisticated editorial technical architecture visual on a genuinely TRANSPARENT alpha background. Landscape 1536x1024. No title, no subtitle, no footer, no enclosing rectangular boxes or card containers. Use small elegant semi-isometric architectural glyphs (documents, people, code editor, cylindrical data storage, shield, servers) on subtle floating planes, fine sage directional connectors, charcoal readable short text labels directly below icons. Muted forest green, warm grey, restrained teal accents. Professional engineering publication, not cartoon, not playful, no mascots, no neon, no heavy shadows. Clear diagram relationships with ample negative space; readable accurate text. No decorative meaningless connections. Diagram content: left 'Builder' person and code editor leading to 'API + Policy' shield at center top. API goes to 'Project context' document stack left center and 'Orchestrator' branching routing glyph center. Orchestrator goes to 'Agent harness' three small connected worker glyphs below center. Project context connects to agent harness. Harness branches right to 'Model gateway' simple neural-node glyph and lower right to 'Sandbox' isolated server with thin dotted oval trust boundary. Sandbox connects to 'Test + Release' checkmark and launch glyph on far right. Below project context 'Postgres + Artifacts' cylinder linked to context. Bottom right 'Audit + Usage' small chart glyph linked to test release. Visual flow left to right with labels. Make 10 labeled nodes total.
